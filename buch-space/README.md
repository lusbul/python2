# Буч 4.0 — Секретна місія на Марс

Відкрийте `index.html` у браузері або на GitHub Pages. Код можна копіювати в Google Colab. Готовий ноутбук `Buch_Mars_Mission.ipynb` можна імпортувати у Colab через Файл → Завантажити блокнот. Дані автоматично створюються у першій комірці; окремі файли також лежать у `data/`.

Навчальна перевірка коду на вебсторінці перевіряє ключові конструкції, **не виконує Python**. Панель учителя `teacher.html` аналізує вставлені коди. Прогрес локальний.
