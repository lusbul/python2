# Escape Room «Чотири ключі» — прототип 2

Інтерактивна браузерна гра для курсу Python 2: списки, словники, кортежі, множини.

## Сценарій
1. **Склад** — вибрати список, оглянути механізм, додати молоко до конвеєра, виправити `add` на `append`.
2. **Сейф** — вибрати словник, змінити кількість зілля інтерактивно, дописати присвоєння за ключем.
3. **Телепорт** — визначити незмінність кортежу, створити нові координати, виправити спробу змінити елемент.
4. **Сканер** — знайти унікальні перепустки, обрати множину та виправити `list` на `set`.
5. **Фінальний замок** — самостійно вибрати структуру для унікальних імен.

## Винагороди
+30 XP за вибір структури; +15 за уважність; +35 за запуск механізму; +10 за експеримент; +50 за виправлений код; +20 за виправлення після помилки; +10 за застосовану підказку; +40 за фінал. Немає штрафів, повторна дія не приносить XP вдруге.

## Техніка
Відкрийте `index.html` або розмістіть папку `four-keys` у корені GitHub Pages. Жодних зовнішніх бібліотек і серверних залежностей. Прогрес у localStorage. Звіт через друк браузера у PDF. Перевірка введених команд — за навчальними шаблонами, **не повний інтерпретатор Python**.
