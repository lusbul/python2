# Escape Room «Чотири ключі: пастка Багстера»

Навчальна браузерна гра для повторення структур даних Python: `list`, `dict`, `tuple`, `set`.

## Запуск
Відкрийте `index.html` у браузері. Для GitHub Pages завантажте `index.html`, `style.css`, `game.js` у корінь репозиторію та увімкніть Pages для гілки `main`.

## Що працює
- Чотири кімнати, які послідовно відкриваються, і фінал.
- Вибір структури або її властивості, уважність, дослідження помилки, редагування коду, підказки.
- Перевірка навчальних Python-команд вбудованим JavaScript-симулятором. Це **не** повноцінний інтерпретатор Python; довільні програми не запускаються.
- Без штрафів: XP за вибір, уважність, експеримент, виправлення та використання підказки. Одноразова винагорода за кожну дію в кімнаті.
- Збереження прогресу у `localStorage` браузера.
- Друк підсумкового звіту в PDF через системне меню браузера.

## Важливо
Це перший робочий прототип, не фінальна повноцінна гра. Для наступної версії можна додати ілюстровані фони, анімовані механізми, більше завдань у кожній кімнаті та повний браузерний Python-рушій.
