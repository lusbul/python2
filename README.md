# Проєктний Python

32 тижневі теми; 4 модулі по 8 тем. Прив’язку до 64 годин прибрано.

## Розміщення на GitHub Pages

1. Розпакуйте ZIP на комп’ютері.
2. Відкрийте потрібний репозиторій GitHub і натисніть Add file → Upload files.
3. Завантажте ВМІСТ папки project-python: index.html, report.html, assets/, lessons/ та інші файли. Не завантажуйте сам ZIP. index.html має лежати в корені репозиторію.
4. Натисніть Commit changes.
5. У Settings → Pages оберіть Deploy from a branch, гілку main і папку / (root), збережіть. Дочекайтеся завершення публікації.
6. Відкрийте опублікований сайт. Перевірте першу тему, звіт і запуск Python на своєму пристрої.

Сайт використовує відносні посилання й підходить для адреси виду https://ім’я.github.io/назва-репозиторію/.

## Що є в темі

Коротка теорія; 3 автоматично перевірювані завдання (прогноз результату, практичне рішення, вибір правильного фрагмента коду); редактор; окреме завдання з ШІ; «Крок до професії»; п’ять додаткових мініпроєктів. Мініпроєкти НЕ входять у звіт та не впливають на завершення.

У першій темі використано сюжети та поняття з наданих матеріалів p2-урок1.pdf та 1(2).pdf. Презентацію в учнівський сайт не вбудовано. Уточнено відмінність ASCII та Unicode.

## Звіт і PDF

Відкрийте «Переглянути звіт / PDF» у темі або «Мій звіт» на головній. У звіті є відповіді, кількість спроб, код, останній запуск, записи роботи з ШІ та професійної задачі. «Друк / PDF» відкриває стандартне вікно браузера: оберіть «Зберегти як PDF». Це друк у PDF, а не автоматичне завантаження окремим PDF-генератором. Мініпроєкти не включаються.

Автоматично перевіряються лише закриті завдання. Статус теми означає 3 правильні відповіді та заповнені відкриті поля (по 5 символів). Якість відкритих відповідей оцінює людина. Запуск коду без винятку не є доказом правильності розв’язання.

## Прогрес

Відповіді зберігаються в localStorage цього браузера. Немає облікових записів, учительського сервера чи автоматичного надсилання звітів. На спільному комп’ютері користуйтеся окремими профілями браузера. На головній є експорт і відновлення прогресу JSON; відновлення замінює поточний стан після підтвердження. Звіт можна створити і для частково виконаної теми.

## Python у браузері

Використано Pyodide 0.27.3 у Web Worker з CDN jsDelivr. Потрібен Інтернет. Початкове завантаження має ліміт 3 хвилини; виконання програми після завантаження — 12 секунд; кнопка «Зупинити» завершує worker. Після кожного запуску середовище створюється заново. Введення для input() задається окремими рядками до запуску. Недостатня кількість рядків спричинить EOFError.

Matplotlib/Pillow завантажуються за потреби. Приклади створюють chart.png та preview.png; результати можна завантажити. У браузері файли тимчасові. Tkinter необхідно зберегти як .py та запустити локально з графічним середовищем. Уроки API/погоди мають збережені вигадані навчальні відповіді, щоб не залежати від доступності сервісу; справжній запит досліджується в окремому завданні. Це не актуальні дані погоди. Файлова автоматизація починається з виведення плану, а не зміни реальних файлів.

## Редагування матеріалів

assets/course.js — теорія, приклади, завдання ШІ та професійні задачі.
assets/extras.js — третя вправа й конкретні описи 160 ідей.
assets/style.css — оформлення й друк.
assets/app.js — інтерфейс, локальні відповіді, звіти.
assets/core.js — облік проходження.
course-content.json — читабельна копія основного змісту. Для зміни сайту редагуйте assets/course.js; JSON-копія не підвантажується автоматично.

У разі відсутності Google Fonts сайт використовує системний шрифт. Усі текстові матеріали доступні без завантаження Python; для локального перегляду відкрийте index.html, але браузерний Python надійніше запускати з GitHub Pages або локального HTTP-сервера.
