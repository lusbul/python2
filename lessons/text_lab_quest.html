1. Реєстрація на подію: наведи лад у даних

Учасник ввів ім'я " оЛеНа ". Система має прибрати зайві пробіли та зробити ім'я придатним для відображення: "Олена".

Операції — перетягни у правильному порядку

На телефоні: натисни на операцію, потім на потрібне місце.

Алгоритм

Для справжнього проєкту: форма реєстрації, база контактів або список учасників мають отримувати узгоджені дані. Зверни увагу: автоматична зміна регістру імен не завжди коректна для складних імен.
def format_name(raw_name):
    return raw_name.strip().lower().capitalize()

print(format_name("   оЛеНа   "))  # Олена
